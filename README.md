CINEX NETWORKS WEBSITE – GITHUB PAGES DEPLOYMENT

Repository: Chameerajayarukshan/cinex-networks-website
Branch: main

UPLOAD
1. Open https://github.com/Chameerajayarukshan/cinex-networks-website
2. Choose Add file > Upload files.
3. Extract this ZIP on your computer first.
4. Upload the CONTENTS of the extracted folder (not the outer folder itself).
5. Ensure index.html is at the repository root and assets/ is beside it.
6. Commit the uploaded files to the main branch.

ENABLE GITHUB PAGES
1. Open Settings > Pages in the repository.
2. Under Build and deployment, choose Deploy from a branch.
3. Select branch main and folder /(root), then Save.
4. Wait for the Pages deployment to complete. The expected site address is:
   https://chameerajayarukshan.github.io/cinex-networks-website/

SITE CONTACT PLACEHOLDERS
The supplied contact page still contains placeholder company phone, email and address values.
The enquiry form also needs the official company email configured in contact.html before it can open a correctly addressed email.
Update these values before announcing the site publicly.
